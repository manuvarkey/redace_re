# Red Baron mod: asset credits

Everything here is original work for the mod or derived from the game's own data. Nothing was downloaded.

| Asset | Source |
| --- | --- |
| RE8, Handley Page O/100, Caquot balloon models (`objects/planes/re8`, `objects/planes/handleypage`, `objects/ground/balloon`, `redbaron.blend`) | Modelled for the mod in Blender by `redace/mods/redbaron/tools/blender_redbaron.py` |
| `textures/fabric*.png`, `wicker.png` | Procedural (`redace/mods/redbaron/tools/redbaron_textures.py`) |
| Albatros and Dr.I paint (`objects/planes/*/*.png`) | Repaints of the game's own atlases (`tools/paint_planes.py`); colours checked against a user-supplied photo of a scale model of the Baron's Albatros D.III (reference only, not shipped) |
| Dawn sky (`redace/mods/redbaron/skies/dawn`) | The game's trenches sky, re-graded (`tools/make_skies.py`) |
| Aerodrome map icon (`redace/mods/redbaron/aerodrome_icon.png`) | Drawn for the mod (8 x 8 pixels, scaled like the game's icons) |

Dimensions used for the models (public reference figures): RE8 span 13.0 m, length 8.5 m; Handley Page
O/100 span 30.5 m, length 19.2 m; Caquot type R about 28 m long and 9.3 m across.

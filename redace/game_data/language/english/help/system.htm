System Specification

The following are the system specifications (requirements) for Master of the Skies: The Red Ace:

  • Windows 95 / Windows 98 / Windows ME
  • Intel Pentium II 233 or equivalent
  • 32Mb RAM
  • Supported 3D Accelerator Card (4Mb minimum)
  • 60MB Free hard disk space
  • SoundBlaster or DirectSound compatible sound card
  • Microsoft compatible Mouse
  • Master of the Skies: The Red Ace supports Direct3D compatible cards with the following chipsets:
    • 3Dfx Voodoo 1, 2, 3, 5, Rush, Banshee, Velocity
    • 3D Labs Permedia 2, Permedia 3
    • ATI Rage Pro Turbo AGP, Rage Pro Turbo PCI, Rage LT Pro, Rage 128, Rage 128 Pro, Rage Maxx
    • Intel i740, i810
    • Matrox G200, G400
    • Nvidia Riva TNT, TNT2, Vanta, GeForce, Quadro, GeForce 2
    • Rendition Verite V2x00
    • S3 Savage 3D, Savage S4, Savage2000
    • Videologic PowerVR Neon 250

    Comments

    • The following video cards unfortunately do not meet the minimum requirements to play the game - Power VR PCX2, Matrox G100, Rendition Verite v1x00, SiS 6326, Nvidia Riva 128, S3 Virge.
    • Users are advised to refrain from minimising the game using ALT/TAB or any other key combination. If access to the Windows desktop is needed we recommend that the game be quit first
    • If any sound or video problems are encountered, we recommend updating to the latest sound or video drivers (see below for our list of recommended video drivers). To check which video drivers are currently being used, run DXDIAG (this can be done by selecting the ‘Run’ option on the START menu and typing 'DXDIAG') and select the ‘Display’ tab. This will list the device name and driver version.
    • If stability problems are encountered when running the game, users are advised to close down all other programs that may be running. Doing this will ensure that Master of the Skies: The Red Ace is able to use the maximum system resources available. To check which other programs are open, press the CONTROL, ALT and DELETE keys at the same time. This will bring up a menu titled ‘Close Program’. This menu lists all the programs currently running, a completely clean system should only have Explorer and Systray listed on this screen. N.B. If you are unsure what the programs currently running are, do not close them unless you are having problems running the game (with either game stability or speed).
    • Laptop Systems - Unfortunately we cannot offer support to users with laptop systems. Due to the wide variety of hardware configurations found in laptops, it is not possible to guarantee compatibility. As each laptop machine can have greatly varying configurations of memory, video, sound, keyboard and most importantly internal architecture it is currently not possible to configure a game that is guaranteed to work on all of them.
    • If any problems are encountered when using the 'Visit the Website' or 'Purchase the Game' options from the games pause menu, we recommend that you use the shortcuts from the START menu to access the Fiendish Games website or get the full version of the game
    • 4/8Mb video cards - Users with video cards that have 8Mb of memory or below may find that their list of selected resolutions in the game is limited or that the game fails to start, displaying the message "Could not open video mode. Ensure DirectX is installed properly.". This problem is caused by the Windows desktop being set at too high a resolution and colour mode, and can be solved by reducing these settings. A Windows desktop setting of 640*480*16-bit colour was found to be the most effective.
    • ATI Rage Fury MAXX - The drivers supplied with this video card (Rage Fury MAXX (1-5-2000) (4.11.01.7925)) will not run Red Ace. Attempting to start the game with them will result in the user being returned to the Windows desktop when they attempt to fly a mission. The problem can be solved by obtaining the latest Special Purpose drivers from ATI (see below for the driver we recommend). This driver can be obtained from ATI's Special Purpose Drivers Page.
    • Nvidia Riva TNT - If any problems are encountered when running the game with the screen flickering, it can be solved by setting the 'Wait for vsync' option in the Video Options menu. If further flickering problems are encountered after this is done, they can be solved by pausing and unpausing the game.
    • Nvidia Riva TNT - If any problems are encountered with a flickering border being present on menu or loading screens, it can be solved by either setting the Windows colour mode to 16-bit colour or by running the game in a resolution of 640*480.
    • Nvidia Riva TNT/TNT2 - Problems were encountered with these cards and some drivers if the game was run in the same resolution as the Windows desktop using a 16-bit Windows colour setting. When the user attempted to exit the game, the screen would remain of the Red Ace menu screen. This problem is caused by driver issues and unfortunately the only solution we can currently offer is to ensure that Windows is either using a different resolution or colour mode to the game.
    • Neon 250 - Minor palette problems may be encountered when running the game with this video card. Unfortunately there is no known solution to this problem at present.
    • S3 Savage 4 - Users are advised not to run the game above 800*600 with this video card as control problems were encountered when doing so.

    Sound Cards

    Red Ace should work with all DirectX compatible sound cards. It has been tested and found to work with the following audio chipsets:

    • Aureal Vortex 1
    • Aureal Vortex 2
    • Creative Labs Sound Blaster 16
    • Creative Labs AWE64
    • Creative Labs AWE64 PCI
    • Creative Labs Sound Blaster 128
    • Creative Labs Sound Blaster Live!
    • Crystal Sound Fusion (Videologic SonicFury)
    • ESS ES1869
    • ESS Maestro I (Videologic Sonic Storm)
    • ESS Maestro II (Videologic Sonic Storm Pro)

    Comments

    • If any audio problems are encountered whilst playing Red Ace, try setting the 'Use Hardware Sound' option in the Sound Options menu to off. This was found to solve audio problems encountered with Creative Labs Sound Blaster Live!, Aureal Vortex 2, Videologic SonicStorm Pro and Videologic SonicFury sound cards.
    • Yamaha 192XG - If any sound corruption is encountered with this card, it can be solved by changing the Hardware Sound Acceleration Level from 'Full acceleration' to 'Basic acceleration'. This can be done via DXDIAG, simply run DXDIAG (this can be done by selecting the ‘Run’ option on the START menu and typing 'DXDIAG') and select the ‘Sound’ tab. From this menu the 'Hardware Sound Acceleration Level' can be set.
    • Videologic SonicFury - If any sound corruption is encountered with this card, it can be solved by changing the Hardware Sound Acceleration Level from 'Full acceleration' to 'Basic acceleration'. This can be done via DXDIAG, simply run DXDIAG (this can be done by selecting the ‘Run’ option on the START menu and typing 'DXDIAG') and select the ‘Sound’ tab. From this menu the 'Hardware Sound Acceleration Level' can be set.
    • Aureal Vortex 1 - Users with Aureal Vortex 1 based sound cards are advised to reduce the sound acceleration level within DXDIAG if any problems are encountered whilst running the game. This can be done via DXDIAG, simply run DXDIAG (this can be done by selecting the ‘Run’ option on the START menu and typing 'DXDIAG') and select the ‘Sound’ tab. From this menu the 'Hardware Sound Acceleration Level' can be changed from 'Full acceleration' to 'Basic acceleration'.

    Joysticks/Gamepads

    As well as mouse and keyboard control, Master of the Skies: The Red Ace can also be controlled using any DirectInput compatible joysticks, gamepads or throttle control systems. The control functions simply need to be redefined within the game.

    You can redefine your controls by going to the Options menu, and then to the Controls submenu. You'll be presented with a list of the controls used in the game, these can be redefined by clicking on them. Once you have clicked on a control function, the cursor will change to a picture of a joystick, and you can then define the control you wish to use by :

    • Keyboard: Press a key on the keyboard
    • Mouse: Press a button on the mouse, or move the mouse in the direction you want to use.
    • Joystick: Press a button on the joystick, or move the stick/throttle control/POV hat in the direction you want to use.

    You can also set the sensitivity of the pitch and roll controls using the bars on the right. You may find this useful if you find the plane a bit too twitchy to control.

    Master of the Skies: The Red Ace should work with any DirectInput compatible controller, it has been tested and found to work with products by the the following manufacturers

    • CH Products - Gamestick 3D, F-16 Combat Stick
    • Gravis - Blackhawk Digital, Xterminator Dual Control, Destroyer, Xterminator, Xterminator Digital, Gamepad Pro, Gamepad Pro USB
    • Interact - Cyclone 3D, Magnum 6, Makopad PC
    • Logic 3 - PC Avenger
    • Logitech - Wingman Extreme Digital, Wingman, Thunderpad Digital
    • Microsoft - Forcefeedback Pro, Precision Pro, Dual Strike, Sidewinder Pro, Freestyle Pro, Sidewinder Gamepad
    • Saitek - P550, Cyborg 3D USB, P2000
    • Thrustmaster - Top Gun USB, Fusion

    Comments

    • USB Controllers - When using USB controllers we recommend that users install DirectX 7.0a or higher on their machine. This revision of DirectX includes better support for input devices. The latest version of DirectX can be downloaded from Microsoft via this link.
    • If problems are encountered with joystick controls being the wrong way round (eg. a throttle wheel on a joystick operating in reverse), setting the 'reversed?' option to on will solve this.

I can't get the game to run.

 Are you sure you have a version of DirectX on your machine? If not this link will explain where to download the latest version from.

Are you sure you have a suitable 3D accelerator in your machine?

Do you have the latest drivers for your video card/3D accelerator? Check on the machine spec page for cards the game has been tested on and which drivers were used.

The graphics appear corrupted.

 Please check the machine spec page for details of problems on specific cards.

If your card is listed as not having problems, check the video driver you are using is the one that was used in the test. Typically if the driver is newer than the one listed the game should also be fine. If you have an older driver, you might want to update your machine's video drivers - do this by going to the web pages of the maker of your video card.

There's no sound

 Are you sure you have

1) A suitable sound card (it must be DirectSound or SoundBlaster compatible).
2) Speakers/head-phones connected to your machine/sound card.
3) Turned the volume up on your speakers/headphones.
4) Turned up the main volume of your sound card, using the taskbar speaker icon.

On the final point - within Windows you can set the volume of sound. To do this
  • On the bottom right corner of the screen double click on the yellow 'speaker' icon.
  • This icon can sometimes appear with a red circle over the top of it - this happens when sound on your system has been muted (disabled).
  • Make sure each of the sliders is at their highest positions.
  • Make sure that all of the 'Mute' and 'Mute All' tick boxes are off (without tick).

The game is slow/hard to control

This is probably because of how the game is configured and/or how your machine is set up. Therefore you need to reconfigure your machine and/or the game in order to increase performance. Please try the following ideas...

1) Make sure you close down everything on your machine except for the game. The other programs will eat up some of your machine's resources. It is especially a good idea to close down mail/internet programs as they can interrupt the game, making gameplay 'jumpy' (stops and starts)

2) If after trying the above you still find the game runs too slowly you might want to upgrade your machine. Here are some of the ways that will improve the performance of the game

  • Memory - More than 128Mb of memory (RAM) will likely make little difference though
  • Processor - Get a faster processor. Check the recommended machine specs for details.
  • Video card - Buy a new 3D accelerator. If you have one of the cards listed in the machine spec page it is probably fast enough.
These are the main features of your machine which will affect the performance of the game.

You can also improve the performance of the game by changing the resolution and detail settings. Choose 'video' from the main menu, and lower the resolution setting, or choose Graphics, and adjust the effects and view distance settings to achieve this.

What do I do if all else fails?

 You can contact our online help staff. Please make sure you have completely read through this page before contacting our staff.

Note that anybody who has purchased a product from us gets a priority service. To get this service please include within your message the name and email address you used to purchase the products.

To help us quickly work out what the problem is you must include the configuration of your machine. You can get this automatically via the output of the 'dxdiag' program.

How to use dxdiag

Here's how to get the output of the Windows application dxdiag...

  • Click on the 'Start' button
  • Select the 'Run...' option from the menu
  • Type 'dxdiag' and press return or click 'ok'
  • This should open the DirectX configuration program, if not go to the list below
  • Click on the 'Save All Information' button at the bottom of the screen
  • Choose a place on your hard disk to save the file (eg c:\)
  • Click 'Save' to save the file
  • In your mail include this complete file
  • You can do this by cutting and pasting the file into your mail
  • Alternatively drag the file into your mail message
If this doesn't work fill in as much of the following as you can in your mail. The more detail you can give us the more easily and quickly we'll be able to find the root of the problem.
  • Name and make of machine
  • What operating system you are using (eg Win95, Win98, NT etc)
  • How much memory (RAM) you have in your machine (eg 32Mb)
  • What sort of processor you have in your machine (eg Intel PentiumII 233Mhz)
  • How much free hard disk space you have in your machine (eg 4Gb)
  • What version of DirectX do you have (eg 3,5,6.1,7 or 8)
  • What video card/3D accelerator you have in your machine (eg 3dfx Voodoo, ATi Rage Pro)
  • What sort of sound card you have in your machine (eg Sound Blaster, AWE64)

What to send

Within the mail please provide

1) The name of the program you used to install the game
2) Where you got the file from
3) Where the problem takes place
4) How often (if applicable) the problem takes place
5) How the problem manifests itself

Thank you for taking the time to provide this information, this will greatly ease the process of finding out what the problem is.

Send your email to support@smallrockets.com, and we will try to get back to you as soon as we can.
Thanks, and sorry for the inconvenience.
